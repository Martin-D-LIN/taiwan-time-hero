# 台灣時空勇者｜Taiwan Time Hero

> 穿越時空，探索台灣，開啟你的冒險之旅！

**台灣時空勇者**是一款以台灣街景、懷舊文化與奇幻科技為靈感的 **3D 即時冒險遊戲**。從老電器行出發，與夥伴一起展開跨越時空的旅程。

## 🎮 立即遊玩

### [▶ 點此開啟《台灣時空勇者》](https://larch.ink/play/VxPkRGl5-vXjhOa0M6cbNzgfHEe4XX-7tp32PQ)

遊戲目前透過 **Larch** 平台提供。建議使用支援 WebGL 的現代瀏覽器開啟；實際裝置相容性以平台為準。

## 🌆 世界觀

復古的台灣街道、雨夜的老電器行、穿越時空的神秘線索，交織成一場融合在地文化與科技幻想的冒險。

## 👥 角色與世界

- **林時雨**：故事中的年輕冒險者
- **阿嬤**：掌握老物件與過往記憶的關鍵人物
- **阿芋**：可愛的像素風鳥類夥伴
- **滑屏狐**：結合奇幻元素與數位科技的狐狸角色
- **即刻配送伯爵、紅點女王、囤積獸**：具有鮮明數位時代特色的奇幻角色

> 以上為角色與美術概念介紹；實際可操作角色、關卡及玩法以目前遊戲版本為準。
